# اجرای Scoreline با دوبارکلیک

1. [شاخهٔ پارت ۲۰](https://github.com/turiwworks-cell/scoreline-brain/tree/codex/part-20-moments) را باز کن.
2. از **Code > Download ZIP** نسخهٔ جدید را بگیر و ZIP را کامل استخراج کن.
3. داخل پوشهٔ استخراج‌شده روی **`Open-Scoreline.cmd`** دوبارکلیک کن.
4. بار اول، نصب وابستگی‌ها انجام می‌شود و اینترنت لازم است؛ سپس مرورگر خودکار باز می‌شود.
5. دفعه‌های بعد فقط همان فایل را دوبارکلیک کن. تا وابستگی‌ها یا نسخهٔ Node تغییر نکرده باشند، نصب تکرار نمی‌شود.

پنجرهٔ اجرا را تا وقتی اپ را بررسی می‌کنی باز نگه دار. برای پایان، پنجره را ببند
یا `Ctrl+C` بزن. برای بازکردن دوبارهٔ صفحه در همان نشست، لینک `Local` داخل پنجره را باز کن.
در حالی که یک پنجرهٔ اجرا باز است، فایل را دوباره اجرا نکن.

صفحه با داده‌های دمو باز می‌شود. پنل توسعه و دکمه‌های `goalHome` و `redHome`
برای بازبینی انیمیشن‌ها در دسترس‌اند. فایل‌های Rive، WASM، عکس‌ها و مسیرهای اپ
از همان سرور محلی بارگذاری می‌شوند.

## اگر Node نصب نیست

پیام اجراکننده این موضوع را مشخص می‌کند. از https://nodejs.org نسخهٔ
**22.12 یا جدیدتر** را نصب کن؛ سپس اجراکننده را دوباره باز کن.
اگر `npm ci` قبلاً برایت کار کرده، احتمالاً نصب لازم از قبل موجود است.

## نکته‌ها

- فایل اجراکننده باید کنار `package.json` بماند؛ آن را به‌تنهایی به دسکتاپ منتقل نکن.
  می‌توانی از آن یک Shortcut روی دسکتاپ بسازی.
- از داخل ZIP اجرا نکن؛ ابتدا کل پوشه را استخراج کن.
- اگر پورت 5173 مشغول باشد، Vite پورت آزاد بعدی را انتخاب می‌کند و همان آدرس را باز می‌کند.
- اجرای PowerShell فقط برای همین فرآیند با `ExecutionPolicy Bypass` انجام می‌شود؛
  تنظیم دائمی ویندوز تغییر نمی‌کند و دسترسی Administrator لازم نیست.
- این اجراکننده، اپ فعلی را باز می‌کند؛ خروجی Rive تازه یا build دستی لازم ندارد.
- اگر شروع نشد، پنجره روی پیام خطا می‌ماند؛ متن همان پیام را ارسال کن.
