# راهنمای سادهٔ فایل Live

خروجی فعلی **26,800 بایت** است و در `public/rive/live-icon.riv` ذخیره شده.
برای این نسخه لازم نیست چیزی را پاک کنی، Artboard را تغییر بدهی یا دوباره خروجی بگیری.
کپسول، قاب بیرونی، نقطه، تقویم، State Machine و Timelineهای موجود را نگه دار.
[گزارش پذیرش و تست‌ها](../reports/part20-live-acceptance.md).

## اگر بعداً بخواهی فایل را ویرایش و صادر کنی

1. فایل اصلی Live را در ادیتور باز کن. آرت‌بورد اصلی با نام دقیق **`aniamtion`** را انتخاب کن؛
   `font` فقط آرت‌بورد کمکی پوشش گلیف‌های فونت است.
2. اندازه و Keyframeهای فعلی را تغییر نده. Runtime در خروجی فعلی **433 × 152** گزارش می‌کند؛
   میزبان آن را تناسبی در قاب با نسبت **443 / 152** و ارتفاع **38** پیکسل رسم می‌کند.
3. State Machine فعلی **`State Machine 1`** و Timelineهای
   `on 2`، `on`، `live to idle` و `idle to live` را نگه دار.
   State Machine خالی آرت‌بورد کمکی، ماشین دکمه نیست.
4. در Data و Inspector آرت‌بورد اصلی، View Model و Instance پیش‌فرض را متصل نگه دار:

| Property | نوع | مقدار اولیه |
| --- | --- | --- |
| `islive` | Boolean | `false` |
| `count` | String | `0` |

5. Text Run عدد تقویم باید از `count` بخواند. در Preview آرت‌بورد اصلی،
   با حالت خاموش `count` را به **0، 3، 12 و 99** تغییر بده؛ عدد باید عوض شود.
   سپس `islive` را خاموش/روشن کن و حرکت کامل دکمه را ببین.
6. فونت **Embedded** و **Glyphs used** بماند. متن کمکی با همان فونت:
   `Live 0123456789`. این متن پوشش همهٔ رقم‌ها را نگه می‌دارد.
   اگر آرت‌بورد کمکی را از Export کنار می‌گذاری، خود متن پوشش فونت را در فایل قابل ویرایش حفظ کن.
7. آرت‌بورد اصلی باید در خروجی Runtime حضور داشته باشد. از **Export > For runtime**
   فایل مستقل `live-icon.riv` بگیر؛ آن را داخل فایل Moments ادغام نکن.
8. حجم فایل حداکثر **60,000 بایت** باشد. آن را در
   `public/rive/live-icon.riv` شاخهٔ پارت ۲۰ جایگزین کن و اپ را rebuild کن.
   شمارنده، کلیک و کیبورد را در اپ هم آزمایش کن.

## چرا انتخاب نام آرت‌بورد لازم است؟

فایل نهایی هم `font` و هم `aniamtion` دارد و پیش‌فرض خود فایل هنوز `font` است.
میزبان نام اصلی را صریحاً به Runtime می‌دهد؛ این انتخاب در constructor و reset اعمال می‌شود.
اگر نام `aniamtion` را عوض کنی، مقدار `artboard` در `src/rive/LiveGraphic.tsx`
و fixtureهای پذیرش نیز باید مطابق آن عوض شوند.

خروجی قبلیِ 23,618 بایتی فقط `font` داشت و رد شد؛ خروجی نهایی آن مشکل را برطرف کرده.
فایل اولیهٔ 243,688 بایتی صرفاً شاهد تاریخی است و وارد `public/` نشده.
