# اصلاح خروجی Live بدون حذف انیمیشن

خروجی دریافت‌شده کل دکمهٔ متحرک را دارد، با Artboard به اندازهٔ `443 × 152`.
کپسول، قاب بیرونی، نشان تقویم و Timelineها را نگه دار؛ ساختار متحرک حذف نمی‌شود.
میزبان جدید کل دکمه را در ارتفاع ۳۸ پیکسل، با همان نسبت ابعاد، نمایش می‌دهد.
قاب و شمارندهٔ DOM فقط هنگام بارگذاری یا شکست Runtime دیده می‌شوند.

## ۱. شمارنده را به داده وصل کن

در View Model فعلی که `islive` دارد، یک Property جدید بساز:

| نام | نوع | مقدار اولیه |
| --- | --- | --- |
| `islive` | Boolean | `false` |
| `count` | String | `0` |

گروه نشان تقویم را باز کن و **Text Run** عدد `12` را انتخاب کن.
مقدار Text آن را با Data Binding به `count` وصل کن؛ جهت اتصال از View Model به Text باشد.
قرار نیست Position، Scale، Opacity یا مسیر حرکت آن را عوض کنی.
نام Artboard یا View Model اهمیتی ندارد؛ نام و نوع این دو Property باید دقیق باشد.
Artboard باید به همان View Model و Instance پیش‌فرض وصل باشد.

در Preview، `count` را به `0`، `3`، `12` و `99` تغییر بده.
عدد داخل همان نشان باید عوض شود؛ متن کمکی دیگری روی آن اضافه نکن.
با `islive=false` و سپس `true`، حرکت رفت‌وبرگشت کامل باید حفظ شود.

## ۲. فونت را کوچک کن

فایل فعلی ۲۴۳٬۶۸۸ بایت است؛ فونت متغیر `DM Sans` به‌تنهایی ۲۴۰٬۱۶۴ بایت دارد.
حذف شکل‌های متحرک برای حل این حجم لازم نیست.

در **Assets**، فونت `DM Sans` را انتخاب کن و گزینهٔ **Include** را از
`All glyphs` به **Glyphs used** تغییر بده.

برای اینکه همهٔ رقم‌های آینده باقی بمانند، یک Artboard کمکی با یک Text Run بساز
و با همین فونت متن زیر را در آن قرار بده:

```text
Live 0123456789
```

هنگام Export، Artboard کمکی را از خروجی کنار بگذار؛ فقط Artboard دکمه صادر شود.
طبق مستندات Rive، حروف استفاده‌شده در Artboard کمکیِ صادرنشده نیز برای
`Glyphs used` حساب می‌شوند.
فونت همچنان Embedded بماند؛ میزبان فعلی دانلود فونت از CDN را غیرفعال کرده است.
وزن فونت، محورهای متغیر، Shapeها و Keyframeها را تغییر نده.

## ۳. خروجی مجدد

فقط Artboard دکمه، View Model/Instance پیش‌فرض و State Machine اصلی
با Timelineهای مورد نیاز صادر شوند.
از **Runtime (.riv)** خروجی بگیر و نامش را `live-icon.riv` بگذار.
بودجه: **حداکثر ۶۰٬۰۰۰ بایت**. اندازهٔ خروجی جدید باید اندازه‌گیری شود؛
کوچک‌شدن مورد انتظار فونت به معنی تأیید بودجه قبل از دریافت فایل نیست.

ابعاد دکمه را در این اصلاح **همان `443 × 152`** نگه دار؛ میزبان با این نسبت آماده شده است.
فایل جدید را مثلاً در `C:\Users\sa\Music\live-icon.riv` ذخیره کن و مسیر واقعی‌اش را ارسال کن.
پس از دریافت، اتصال واقعی `count`، اندازه و رفتار فایل جایگزین دوباره بررسی می‌شوند.
خروجی فعلی فقط به‌عنوان شاهد آزمایش در
`verification/rive/exports/live-icon.original.riv` نگهداری می‌شود؛
هنوز جایگزین نهایی `public/rive/live-icon.riv` نیست.
